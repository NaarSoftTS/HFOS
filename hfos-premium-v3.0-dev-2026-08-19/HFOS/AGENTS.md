# Human Flourishing OS — Kernel

_Every runtime enters here. Ceiling: ~100 lines. Story + route — never dumps._

## Why

This system exists so its operator can stay grounded, decide well, and ship work that matters — AI carries the mechanics; the person stays the author. (Name this OS your own way in your first session.)

**Covenant:** AI prepares · person chooses · workspace carries context · system remembers · work produces evidence.

**Standing check:** a system that becomes more impressive while the person becomes less free has failed.

## What

Eight rooms — folder names coach thinking:

| Room | Verb | Holds |
|---|---|---|
| `foundations/` | GROUND | Identity, purpose, values, direction *(write only on explicit instruction)* |
| `life/` | STEWARD | What's entrusted to their care |
| `relationships/` | INVEST | People who matter |
| `workspaces/` | BUILD | Work brought into the world |
| `momentum/` | MOVE | Short list where movement is in question |
| `system/` | EMPOWER | Wisdom, agents, skills, loops, tools |
| `inbox/` | CAPTURE | Everything enters; nothing lives here |
| `exports/` | SHIP | Stub → `@resources/exports/<workspace>/` holds shipped files; not brain |

**Layers (apart on purpose):** knowledge with its subject · judgment in `system/` · action via momentum / loops / tools.

## How a session runs

**Always (only):** (1) this file · (2) `NOW.md` · (3) `foundations/SUMMARY.md` → then **route narrow** to owning workspace / project / life / person. Don't announce loads.

**JIT (narrowest last):**
- Judgment — `system/wisdom/CORE.md` + 0–2 facets (`system/wisdom/README.md`)
- Domain face — HOME / FOUNDATIONS / STATE / NEXT; people file before writing about someone
- Craft — one skill and/or one **team** lens for **high-function** only. Default: zero team lenses (`system/team/`)
- Doctrine — one core file · one job-pack playbook on trigger
- **Session end** — append one ask-ledger line: `date · class > use-case · subject > project` (`system/skills/system-adaptation/SKILL.md`); mechanics only, never content

**Motion:** Ground → Clarify → Decide → Act → Build → Ship → Learn → Grow.  
**States:** Captured → Exploring → Chosen → Committed → Moving → Blocked → Ready to Ship → Shipped → Learned.  
Act ≠ Build · Chosen ≠ Committed · Shipped = landed · Learned = reflection ran. → `system/core/MOTION.md`

## Gates (hard)

1. **Nothing leaves without the person** — no send, publish, spend, commit in their name.  
2. **Compass is the person's** — direction + `foundations/` change only by their act.

A recommendation never silently becomes a decision, commitment, task, or memory. The adapter states what the harness cannot enforce.

## Invariants

Pointers never copies · fail closed on bad pointers · truth with subject (not `system/memory/`) · scripts measure, models judge · nothing scaffolds empty · ceilings: branch then compress · care ≠ pipeline · money never stands alone · sources ≠ brain.

## Where things go

| If it… | → |
|---|---|
| Prescribes behaviour | `HOME` / `FOUNDATIONS` at right level |
| Current truth | subject's `STATE.md` |
| Permanent decision | `DECISIONS.md` |
| Evidence | `TIMELINE.md` |
| Needs *them* | `momentum/NEEDS_ME.md` |
| Promised to a human | `COMMITMENTS.md` + evidence pointer |
| Stalled | `BLOCKED` (chase) / `WAITING` (clock+check) |
| Awaits release | `READY_TO_SHIP.md` |
| Recurring person | `relationships/people/[slug].md` |
| Transient contact | context `PEOPLE.md` |
| Just arrived | `inbox/` |
| Heavy binary / code / publish | outside tree; ship → `@resources/exports/<workspace>/` |
| Source / raw / full-text dump | `@resources/library/…` + short **SOURCE** pointer — load only to process source |

Unsure → propose path and ask.
