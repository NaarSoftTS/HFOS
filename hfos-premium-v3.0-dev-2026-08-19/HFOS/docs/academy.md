# The Academy & community

_What the membership adds. The system you own is complete without it — this is what keeps it compounding._

## What membership carries

- **Monthly updates** — upgrade packets your own system applies (`upgrade-guide.md`). More ships when it's ready; monthly is the promise
- **The Academy** — the operator curriculum: getting real leverage out of workspaces, momentum, the coach, and the specialist bench
- **The support agent** — an AI trained on these patterns, answering setup and usage questions any hour
- **The community** — operators comparing builds, sharing patterns, and helping each other. People helping people is the model; this was never a support-contract business

## What membership is not

Not a license: the system is yours forever regardless. Not a lock-in: month-to-month, cancel anytime, keep everything installed. Not required: docs + community knowledge cover normal operation.

## Where

Community, Academy, and membership details: **`CARD.md` at your tree root** — locations live there rather than here so this file never goes stale.
