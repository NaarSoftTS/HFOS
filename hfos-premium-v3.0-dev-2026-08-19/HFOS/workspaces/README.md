# Workspaces

_Work brought into the world. Each workspace is one body of work — a business, a venture, a nonprofit, a big project. One works; many work; use whatever shape your life actually has._

## Standing one up

Ask your OS: **"Set up a workspace for [name]."** It creates `workspaces/<slug>/HOME.md` — one page saying what this is, what it's for, and where things go. That's all a workspace needs at birth.

## A workspace grows only as it earns depth

| File | Appears when |
|---|---|
| `HOME.md` | Always — the front door |
| `FOUNDATIONS.md` | It has its own purpose/identity worth stating |
| `STATE.md` | Current truth needs one canonical place |
| `DECISIONS.md` | The first permanent decision is made |
| `TIMELINE.md` | Evidence worth keeping starts landing |
| `projects/<name>/` | A project has a real definition of shipped |

Create-on-first-write. Empty folders are worse than absent folders.

## The line this room draws

Workspaces hold what might one day be **shared** — with a partner, a team, a collaborator. What's personal lives in `life/`, which is never the shared surface. Keep the two apart and sharing stays simple forever.
