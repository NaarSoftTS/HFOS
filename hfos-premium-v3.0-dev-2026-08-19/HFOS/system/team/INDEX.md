# Team — specialist lenses

_Load a team lens only for **high-function work** where a specialist view changes quality. **Zero lenses is the default.**_

This install's team files live at `system/team/<slug>/TEAM.md`. (If your tools say "agents," treat that word as an alias for team lenses.)

## Load rule

1. Default: no lens. Kernel + owning context + wisdom-on-judgment is enough.
2. Load when average vs excellent would change the outcome.
3. One primary lens per question; a second only if two disciplines truly share the work.
4. Never ambient-load the roster.
5. Brief with: question · what's live · constraints.
