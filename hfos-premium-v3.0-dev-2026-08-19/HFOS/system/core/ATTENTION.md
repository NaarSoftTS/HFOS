# Attention & Prioritization

_JIT — load when ranking, briefing, planning, or choosing what to work on. Ceiling ~100 lines._

**Claim:** attention is scarcest and misallocated by default toward urgent, blocked, recent, and well-documented noise — away from what matters. Season calibration (`NOW.md`) sets what matters; this file governs day-to-day spend.

---

## One environment at a time

Group by context (workspace / project / life / person), then rank within it. Interleaving six workspaces line-by-line is not a summary.

## Three progress classes

| Class | `class::` | Inference |
|---|---|---|
| **Move the Mission** | `mission` | Defining decision, high-leverage opportunity, material risk/relationship — **deep reasoning** |
| **Build Momentum** | `momentum` | Advances an active outcome — **focused reasoning** |
| **Clear the Path** | `path` | Loose end / approval / ambiguity — **quick resolution**, batched |

Path earns deep reasoning only if the answer could materially change a decision, person, commitment, or risk — then reclassify.

**Every `mission` item names its outcome.** No named outcome → not mission.

## Two axes (+ energy)

| Axis | Sets |
|---|---|
| **Consequence** | Where it surfaces |
| **Need** | How much reasoning |
| **Energy** | When to meet it: **prime** · **relational** · **steady** · **light** · **recovery** (protected, never leftover) |

A high-consequence invoice that needs a chase surfaces high and gets a chase — not nightly deliberation. A quiet defining decision still surfaces — absence of noise is not absence of weight.

## Context tiers (season calibration)

| Tier | System does |
|---|---|
| **Lead** | Deep inference; coach when something moved; first on surfaces |
| **Advance** | Focused forward motion on active outcomes |
| **Maintain** | Commitments + path clears; watch class changes |
| **Watch** | Awareness only — never competes for strategy |

Tiers move only via `NOW.md` with a reason — never loop inference. Past ~3 Lead contexts, Lead allocates nothing (health flags; no auto-demote).

## Coaching Lead work

When something moved or today offers a move: (1) what matters now as changed reality · (2) why · (3) one best next move. Unchanged Lead → one line, still-standing next move. Restating the same paragraph daily = wallpaper.

**Surfacing ≠ deciding.** Mission-class stuck >1 week gets a **prepared decision** (options, assumptions, recommendation) — the system spends inference so the person spends judgment.

## Minimum meaningful move

When a context can't get real attention today: smallest action that reduces uncertainty, creates commitment, unlocks work, or protects an outcome — and still traces to something real. Easy activity is not a substitute.

## Importance impostors

Do **not** treat as importance: urgency · blockage · repetition · task size · recency · available documentation. Test: **what meaningful outcome does this affect, and how materially?**

## Who applies

| Surface | Role |
|---|---|
| Sweep | Assigns `class::` at capture; person corrects |
| Briefing | One human surface — tier order, class depth, energy when, path batch |
| Planning session | On-call altitude, convened on purpose |
| Overnight builder *(when installed)* | Tier then class; dispatch coaches briefing |
| Mirror (health) | Did inference follow consequence? |

## Honesty checks

- Class inflation audited (if everything is mission, nothing is)  
- Tier inflation audited  
- Class follows evidence, not yesterday's label  
- Person's reclassification is final and teaches
