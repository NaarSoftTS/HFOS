# Architecture — How This OS Works

_JIT — system improvement, audit, onboarding the OS itself, packaging. Kernel is `AGENTS.md`._

**Auditable:** if the system and this page disagree, the disagreement is the finding.

---

## One spine

Identical tree every install. Levels add loops/agents; they never restructure. Rooms coach purpose.

| Level | Feel |
|---|---|
| **L1 — work in it** | Full tree, lenses on demand, maintain loops |
| **L2 — works for you** | + overnight builder + scheduled morning briefing |
| **L3 — runs with you** | + fuller lenses, Mirror, rich ledgers; overnight compounds; surfaces only Needs You |

L1→L2 is commitment. L2→L3 is scale. **This box ships L1 complete;** L2/L3 capabilities (overnight builder, richer surfaces) arrive as upgrade packets via one channel. **Nothing forks.**

## Three layers

| Layer | Where | Rule |
|---|---|---|
| Knowledge | foundations, STATE/DECISIONS, people, library | Truth with subject |
| Judgment | wisdom, agents, skills, playbooks, core | How to think — no portfolio baked into lenses |
| Action | loops, tools, momentum, exports | What happens |

Mix them → stale agents or un-updatable workspace files.

## Invariants (checkable)

1. Current truth with subject — memory is history *(freshness-sweep)*  
2. Foundations never silently rewritten *(gate)*  
3. Recommendation ≠ decision/commitment/task/memory *(MOTION.md)*  
4. Pointers, never copies *(momentum-lint, schedule-diff)*  
5. Scripts mechanics; models judge *(runbooks)*  
6. Host detail only in adapters *(check-paths)*  
7. Pointers resolve *(orphan-scan; coverage limits apply)*  
8. Ceilings: branch then compress — never raise quietly *(check-ceilings + SIGNAL)*  
9. Unresolvable runbook → fail closed  
10. Nothing scaffolds empty  

## Actors

| Actor | Does | Never |
|---|---|---|
| Person | Direction, choice, release | Script work |
| Builder (overnight/session) | Build within autonomy | Send/publish/spend/sign; decide what matters |
| Agent | Discipline lens — high-function only | Know operation; default load; act alone |
| Skill | Procedure | Decide it should run |
| Tool | Measure | Interpret |
| Loop | Recur on clock | Edit self/schedule |

Planning altitude = a planning session convened on purpose — not a standing actor.

## Chains

**Nightly (when the overnight chain is installed):** sweep → builder → briefing (+ weekly prune). The builder finds+builds from evidence + attention — not plan-queue. **At install: the on-demand morning brief only.**  
**Monthly:** health + person-led reset (outside overnight).  
Defs: `system/loops/`, `system/automations/`.
