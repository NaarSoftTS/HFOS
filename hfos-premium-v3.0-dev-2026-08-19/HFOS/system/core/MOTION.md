# Motion — Loop, States, Reflection

_How work moves. **Not ambient** — load when staging work, reporting state, shipping, or learning. Kernel holds the one-line loop + state chain only._

**Loop:** Ground → Clarify → Decide → Act → Build → Ship → Learn → Grow  
**States:** Captured → Exploring → Chosen → Committed → Moving → Blocked → Ready to Ship → Shipped → Learned  

The loop is wired into the tree — stage ≈ where the work lives. States are the only words loops/agents use for progress.

---

## Loop stages

| Stage | Question | Lives in |
|---|---|---|
| **Ground** | What is true, and what matters here? | `foundations/`, `NOW.md`, owning context |
| **Clarify** | What are we trying to make true? | `HOME.md`, `PROJECT.md`, optional `OUTCOMES.md` |
| **Decide** | What are we choosing — and not? | `DECISIONS.md`, wisdom, Whole-System Check when consequential |
| **Act** | What needs to happen *now*? | `NEXT.md`, `NEEDS_ME`, commitments |
| **Build** | What must be created or completed? | project `working/` — **test while building** |
| **Ship** | What makes this ready to create value? | `deliverables/`, `READY_TO_SHIP`, `exports/` — **person releases** |
| **Learn** | What happened, and what did it teach? | reflection below · `TIMELINE` · lessons |
| **Grow** | How do we get better at what works? | skill/playbook/calibration/person capability |

**Act ≠ Build.** Projects die two ways: never start (needs Act) · start and never finish (needs Build). Collapsing them hides one failure.

**Ship** is a gate question, not a file move. Untested work at Ship skipped Build. Unreachable store → still Ready to Ship, placement named.

**Learn is not optional. Grow is not a mood.** If a full turn produced no capability change, Grow didn't run. Skipping Learn repeats expensive mistakes sincerely.

### Help by stage

- Clarify → outcome as changed reality, not a build plan  
- Act → next move, not more analysis  
- Build → do not re-litigate decisions; reopen only as an explicit finding  
- Ship→Learn gap → most common silent failure  

Altitude: season turns the loop once; a project several times; a session may turn it entirely.

## States

| State | Means | Lives in |
|---|---|---|
| **Captured** | Exists; nothing more claimed | `inbox/` |
| **Exploring** | Examined, not chosen | workspace `possibilities/` |
| **Chosen** | Worth doing (internal, reversible) | `PROJECT.md` / mature `OUTCOMES.md` |
| **Committed** | Someone holds us to it | `COMMITMENTS.md` — **gate 1; only the person** |
| **Moving** | Work happening | `NEXT.md`, `working/` |
| **Blocked** | Chase would move it | `BLOCKED.md` — **name person + release** |
| **Ready to Ship** | Finished, gated, awaiting release | `READY_TO_SHIP.md` |
| **Shipped** | Landed where it creates value | `exports/…` manifest |
| **Learned** | Reflection actually ran | `system/memory/lessons/` |

*Waiting* is not a work state — external clock on a stalled item (`WAITING.md` + check date).

_Ledger names are canonical; their shape is the build's: five files under `momentum/` (full) or sections of `momentum/MOMENTUM.md` (simple) — same grammar either way._

### Transitions that matter

- **Captured → Exploring** is deliberate promotion (explore rule). Inbox must not become an unchosen backlog.  
- **Chosen ≠ Committed.** Conflating them is how portfolios overcommit. Agents recommend; they never enter commitments.  
- **Moving → Blocked** requires person + release condition. Vague "blocked on vendor" = unowned.  
- **Ready → Shipped** is a gate. System prepares; person releases; artifact must actually land.  
- **Shipped → Learned** is the one most skipped — gap is meant to stay visible.  
- **Not-now** may leave the sequence anytime — intentional defer with reason; not guilt. Three reviews still not-now → drop honestly.

**Under all of it:** a recommendation never silently becomes a decision, a commitment, a task, or a memory.

## Reflection (Learn)

Run when: project ships · outcome review point · commitment releases/breaks · failure/surprise · monthly reset · Mirror (priorities vs attention).

| # | Ask |
|---|---|
| 1 | What happened? (neutral) |
| 2 | What did we expect? (**from record**, not memory) |
| 3 | What was actually true? (model vs world) |
| 4 | What was in our control? (sort accurately) |
| 5 | What changes? (concrete artifact edit — or "nothing, and why") |
| 6 | What do we keep? (name what worked) |
| 7 | Continue / adapt / pause / stop? (**chosen**, never default-continue) |

**Posture:** no shame, no spin, no avoidance. A reflection that finds no miss didn't run; only misses = shame. Honesty takes longer (Q3).

**Output:** Q5 → the artifact · lesson → `system/memory/lessons/` (1–2 lines) · Q7 → OUTCOMES/DECISIONS · evidence → TIMELINE. A lesson only in chat was not learned by the system.
