# Trace — what work must answer to

_JIT — board/planning, Hero, briefing when claiming importance. Ceiling ~60 lines._

## The ladder (top → bottom)

| Rung | Lives in | Notes |
|---|---|---|
| Values & personal purpose | `foundations/` | Always; never blocks |
| Workspace purpose & vision | workspace `FOUNDATIONS.md` | Every workspace |
| Objectives | Hero `state/objectives.md` | **Derivable** |
| Outcomes | context `OUTCOMES.md` | **Optional; earned by maturity** |

Trace by naming what it serves at the **highest honest rung**. Missing higher artifact = tree gap to surface, not item failure.

## Rule (replaced the old gate)

**Nothing gets queued that cannot name what it serves. Everything else proceeds.**

Finding, not block. Loop writes the gap and carries the question — does not drop work or invent a target.

**Why no outcome gate:** a wide fast portfolio cannot keep full outcomes current. A rule quietly optional teaches every gate is negotiable.

## Deriving an objective

When work is real and no objective covers it:

1. Read down from workspace `FOUNDATIONS.md` (+ foundations if thin)  
2. Write objective with `derived::` rung + date + tier why  
3. Use same night — working target until the person corrects  
4. Record corrections (teach next derivation)  
5. Reconcile — replace derived when real OUTCOMES land; don't stack  

**Never:** write upward into foundations; never treat derived as commitment/decision/direction.

## Still hard

## Through-line

Every workspace: genuinely good work **and** human flourishing impact — life made whole, work made fruitful, good that overflows (the owner's `foundations/` gives it their meaning). Second is core purpose, not garnish — valid rung when nothing more specific exists yet.

## Propagation (structural watch)

Context descends easily; purpose language can strand in library/captures without ascending to `foundations/` or workspace FOUNDATIONS. Mechanisms: derive flags thin purpose · health checks empty why · foundations proposals are pending gates with cost, not filed wallpaper.
