## Design rules for this folder

- **Kernel stays thin** — story + gates + route + find map only  
- **One concern per live file** — merge when two files always load together  
- **History and long rationale branch** — don't bloat hot doctrine  
- **Values outrank checklists** — checks cite `system/wisdom/` + foundations; they don't replace them
