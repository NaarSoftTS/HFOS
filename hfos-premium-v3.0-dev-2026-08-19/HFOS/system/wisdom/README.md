# system/wisdom/ — Operating Wisdom (engine)

**Upgradeable engine substrate.** Judgment spine for agents, loops, skills, and gates.  
**Not** the owner’s identity — that stays in `foundations/`.  
Owner convictions *constrain* this package; they are not replaced by it.

| Layer | Path | Touch rule |
|---|---|---|
| Owner compass | `foundations/` (identity, purpose, values, boundaries, voice, direction) | Human gate only |
| **Operating wisdom** | **`system/wisdom/`** (this folder) | Upgrade packets OK (merge/adapt) |
| Role craft | `system/agents/*/WISDOM.md` | Must not contradict CORE |

---

## Load protocol

**Session default:** `foundations/SUMMARY.md` only (short wisdom card + pointer here).  
**On judgment / gates / writing as the person / agents:** load `CORE.md` (never skip).  
**Overnight/build loop work (if installed):** `CORE` + `build` (± `people` if human impact; ± `discernment` when choosing among missions).  
**On-call planning session** (skill; optional weekly): `CORE` + `discernment` ± `build`/`people` — **not** full package by default.  
**Other work:** JIT one facet by task (table below).  
**Never** silently rewrite `foundations/`.

| File | Load when |
|---|---|
| `CORE.md` | Judgment, gates, agent action, means/ends, checks, outbound in their name |
| `discernment.md` | Decide, prioritize, research, counsel, risk, season, “what should we do” |
| `character.md` | Overwhelm, pace, rest, tone, saying no, habits, recovery, calendar/energy |
| `build.md` | Deals, money, offers, product, ship, ops, capacity, metrics, partnerships, craft |
| `people.md` | Named humans, conflict, care, hire/release, formation, hard conversations |
| `roots.md` | Source/exegesis only |
| `foundations/principles.md` (owner catalog) | Index/catalog only — not a second full load |
| `README.md` | This protocol |

**Owner overlay:** After CORE, if the work touches calling/season/boundaries, also honor `foundations/SUMMARY.md` and any file it points at. System wisdom never outranks a boundary.

## Task → load map (high-traffic)

| Incoming task | Load |
|---|---|
| Morning briefing / what needs me | `CORE` ± `people` ± `discernment` |
| Overnight sweep / intake *(when installed)* | `CORE` (evidence + no invent) |
| Overnight builder / find / build / implement *(when installed)* | `CORE` + `build` ± `people` ± `discernment` when ranking missions |
| Ship review | `CORE` + matching facet |
| Flourishing check | `CORE` + `build` and/or `people` |
| Whole-system check | `CORE` + `discernment` ± domain facet |
| What should I work on / decide | `CORE` + `discernment` |
| Deal / price / contract / raise | `CORE` + `build` + `people` |
| Email/message **as the person** | `CORE` + `people` + `character` + voice |
| Hard conversation / conflict | `CORE` + `people` + `character` |
| Overwhelm / say no / rest | `CORE` + `character` |
| Pure code / mechanical | `CORE` agents section only |
| Capital pipeline | `CORE` + `people` (+ `build` if money mechanics) |
| On-call / optional weekly `planning-session` | CORE + discernment ± build/people (not full dump) |

**Three stacks to memorize:**  
1. Priced offer + named person → CORE + build + people  
2. Strategic fork, no counterparty → CORE + discernment  
3. Burnout while shipping → CORE + character (+ build if system is the wound)

**Unclear:** CORE only → field tests → add facet the first failure points at.

## Judgment stack — values first

**Strong values beat stacked checks.** Do not run every instrument on every task.

| Layer | What | When |
|---|---|---|
| **1 · Compass** | `foundations/SUMMARY.md` → filters, boundaries, voice as needed | Always in session; deepen when choice tests them |
| **2 · Engine spine** | `CORE.md` + 0–2 facets (map above) | Judgment, gates, agents, writing as the person |
| **3 · Plan-gate procedure** | `system/skills/flourishing-check/` — the gate that asks *"should this exist?"* | Shaping offers/products/plans — person on the other end |
| **4 · Direction check** | `system/core/WHOLE-SYSTEM-CHECK.md` | Consequential direction/money/reputation/obligation only |
| **5 · Ship-gate procedure** | `system/skills/reveal-check/` — may this leave? | Before anything reaches another human |

Layers 3–5 **cite** 1–2; they must not restate a second canon. Portfolio altitude planning: skill `planning-session` (on-call) — not a check layer.

## Rules

- Cross-cutting **engine** truths only. Owner biography → `foundations/`. Workspace values → workspace `FOUNDATIONS.md`.  
- Role `WISDOM.md` must not contradict `CORE.md`.  
- Grow by compression in the right file.  
- Filters (portfolio sort): `foundations/COMPASS.md` § Filters.  
- On CORE change → refresh Wisdom card in `foundations/SUMMARY.md` (pointer text only).  
- Upgrade packets may ship this folder; they still **must not** silent-edit owner foundations without a foundations gate.
