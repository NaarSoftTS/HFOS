# Connections — capability register

_What this OS can reach, stated honestly. **Gaps are named, never papered over.** The adapter (`cowork.md` or your active harness page) maps each capability to a concrete connector; this page is harness-neutral._

| Capability | Status at install | Notes |
|---|---|---|
| Mail | **not connected** | Connect your own account in your agent app; the OS drafts, **you send** |
| Calendar | **not connected** | Read/write once connected; scheduling suggestions stay proposals |
| Task system | **not connected** | The OS works fully without one — `momentum/` is the action surface |
| Files / cloud drive | **not connected** | Local tree is the default truth |
| Web research | per your agent app | Whatever your harness provides |
| Accounting / revenue | **absent by design** | Financial facts enter by your word or documents you share |
| Transcription / meetings | **not connected** | Paste or drop transcripts into `inbox/` |

**Rules:** a capability not listed here doesn't exist for this OS — loops and agents must not assume it. A connector that lists is not a connector that works; verify with one real call before relying on it. Every new connection gets a row here **and** in the adapter, same session.
